# Personal Knowledge Agent

Windows 個人知識助理的開源開發原型，MIT 授權。以本地 SQLite FTS5 搜尋 Markdown、HTML、PDF、Word、Excel 與 CSV，提供來源位置、可校對的 OCR／表格衍生文字、可選 OpenAI 或本地模型問答。專案仍在開發，尚非完整正式產品。

## 隱私與安全

來源文件以唯讀方式存取，索引及工作副本存於獨立資料目錄。外網 AI 連線預設關閉；啟用後每次請求前會預覽欲傳送的問題與片段。OpenAI Key 使用 Windows 憑證管理員，請勿提交 Key、文件、索引、`.pka` 備份或本機 `data/`。AI、OCR 與掃描表格結果需要人工核對。

## 本機開發

需要 Windows、Python 3.12、Tkinter 與支援 FTS5 trigram 的 SQLite。安裝 `requirements-dev.txt` 的依賴後執行 `python app.py`。首次使用須選擇資料來源，程式不得放在來源資料夾內。測試：`python -m unittest -v test_core test_ai test_package test_budget test_pdf_features test_installer test_adb test_research test_review`。特定 OCR 測試會在本機引擎或語言資料不可用時跳過。

PDF 預覽使用 pypdfium2；文字型表格使用 pdfplumber。Windows OCR 可使用已安裝的辨識語言；Tesseract OCR 需要自行安裝 Tesseract。簡體中文語言資料可由使用者另行取得官方 [tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast)，並放在 `data/ocr/tessdata/`；第三方資料有其自身授權。程式不自動下載模型。

## 已知限制

批次 OCR 限同一文件每次 25 頁，產物須校對後才能供 AI 引用；掃描表格依文字位置推測，複雜表格和合併儲存格不保證正確。`.pka` 不加密，真實大型資料庫需另做還原演練。OpenAI 費用是按使用者填寫單價的 APP 本地估算，不是官方帳戶餘額。

程式尚未具備簽章更新、自動解除安裝、完整版本還原及正式 Tauri 介面。

## ADB 裝置探索與研究模式

支援 Android 閱讀器截圖、視覺模型規劃、每一步人工確認、待校對步驟紀錄與截圖備份。型號與韌體差異可能影響 ADB 行為，尚需實機驗證；不支援自動執行任意命令。

研究模式允許自由輸入品牌、型號與韌體，也可在使用者選擇後唯讀取得已連線裝置資訊，經使用者確認後以 OpenAI Responses API 網路搜尋公開資料、顯示來源並建立待驗證筆記。不會執行研究到的指令。本機模型仍可供文字／視覺問答，網路研究目前需要 OpenAI。網路研究會以使用者設定的模型和搜尋工具單價預留費用；估算不等於官方帳單，也不保證不超支。設定預算時須先設定網路搜尋單價。

發行時請分別遵守並隨發行包附上 Android Platform Tools、Tesseract、其語言資料及其他依賴的第三方授權。程式碼採 MIT；不代表上述第三方元件皆為 MIT。請勿提交使用者知識庫、截圖、憑證、備份或日誌。

AI 研究與裝置觀察紀錄可在文件管理中進行人工核對、撤回及查看歷史；編輯後回到待審核，網路研究即使已核對仍不代表裝置實測。

## 可選內建本地模型

可攜版可由使用者明確選擇下載 Google Gemma 4 26B A4B Q4 模型與圖片組件，按鈕啟動或關閉，不依賴 Ollama。下載固定版本並檢驗 SHA-256；模型不自動下載，也不包含在知識庫封裝中。模型檔及本地使用者資料不可提交至 Git。使用者可保留或選擇其他本機服務。

執行程式需另行隨發行包放置於 `local-ai/runtime/`（Windows x64 llama.cpp，含相依 DLL），模型置於 `local-ai/models/`。模型與 llama.cpp 有各自的第三方授權；發行時應附授權資料。請先實測模型與硬體，32 GB 的可用記憶體和推論速度因環境而異。測試另包括 `python -m unittest -v test_local_ai`。

模型下載支援中斷續傳與完整雜湊驗證；啟動中可取消，無法使用顯示卡時嘗試 CPU。閱讀器探索在 OCR 階段停止後不再送出尚未開始的 AI 請求；已送出的請求或裝置動作不能撤回。

合成文件的搜尋品質測試：`python -m unittest -v test_search_quality`。測試結果不能代表真實資料或所有機型的品質。來源狀態使用修改時間、大小及檔案屬性快速檢查；大小與時間皆不變時仍可能漏掉內容變更。

檔名可協助排序品牌和型號，指定單一型號時會嘗試限制相關來源；此為規則式判斷，可能漏掉通用文件，仍須核對來源。使用者確認傳送時，AI 收到顯示的檔名與片段，不額外收到完整路徑。

內建 Gemma 問答要求模型提供各引用的短片段，逐字驗證片段屬於對應的已擷取資料，驗證失敗最多重試一次。驗證不代表模型的推論正確，擷取內容可能來自 OCR 或 AI 知識卡；其他模型目前不使用此驗證。

內建模型會對部分操作關鍵詞缺漏顯示提示；這不是語意驗證，無警示仍不能保證正確。

內建模型的遺漏提示也檢查引用來源中與問題相關的句子；若模型稱資訊不足但來源可能有步驟，會提醒查看。規則僅提供提示，可能誤報或漏報。

問答預覽可選擇要送出的來源，並顯示來源類型。文件管理可從索引及已校對的 PDF 衍生文字建立獨立知識卡，會檢查來源狀態並記錄索引雜湊；AI 紀錄仍需在原卡審核。文件管理測試：`python -m unittest -v test_document_management`。

批次匯入顯示每檔結果；明確匯入原始來源時建立獨立副本，已有副本需驗證雜湊。解析失敗與沒有可搜尋文字會明確標示，原始來源不會修改。

最近匯入結果可重試解析失敗與未處理項目；已保存的副本先驗證 SHA-256，然後重新解析同一副本。清單目前不跨視窗或重啟保存。

匯入批次、逐檔結果與嘗試歷程保存在知識庫；重開後可選擇批次重試。已保存副本以文件 ID 關聯，還原與搬移後可使用新路徑。來源路徑屬於匯入紀錄，會包含在未加密的 `.pka` 中。測試：`python -m unittest -v test_import_history`。突然中斷單檔複製仍可能留下未登記的暫存或副本。
